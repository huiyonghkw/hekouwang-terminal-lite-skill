FAQ常见问题

Will upgrading overwrite my existing config?升级会不会覆盖我现有的配置？
No. unlock.sh unpacks the paid zip over the lite directory with a snapshot first — if a step fails it rolls back automatically. ~/.zshrc is backed up to ~/.hekouwang-terminal-backups/, and your own aliases / PATH are moved into ~/.zshrc.local by migrate.sh. It takes over instead of overwriting.不会。unlock.sh 把付费包解压覆盖进 lite 目录，先快照备份、失败自动回滚；~/.zshrc 先备份进 ~/.hekouwang-terminal-backups/，自定义 alias / PATH 由 migrate.sh 搬进 ~/.zshrc.local——接管而不是覆盖。
What happens when the license expires?到期后会怎样？
No auto-renew. For one year from purchase you get free updates and group Q&A. After that, what you already installed keeps working indefinitely — you just stop receiving new versions and Q&A. Renewing or not never takes away anything you already have.不自动续费。购买之日起一年内可免费获取更新并在群内答疑；一年后已安装的版本可继续无限期使用，只是不再提供新版本与答疑。续期与否不影响你已经拿到的任何东西。
How does SkillHub per-call billing work?SkillHub 按次怎么算？
¥2.99 per call, no free calls. Roughly 20 calls ≈ one year of SkillPay. Use it when you only need theme generation / optical prescriptions occasionally.¥2.99/次，无免费次数，约 20 次 ≈ SkillPay 一年。只是偶尔要主题生成 / 光学处方时适合按次走。
Trial or refunds?有试用或退款吗？
Trial is 0 — the free lite build is the trial. Purchases and refunds follow the rules of the platform you bought from (Alipay SkillPay / Tencent SkillHub).试用 0——免费 Lite 版本身就是试用。购买与退款遵循对应平台（支付宝 SkillPay / 腾讯 SkillHub）的平台规则。
Will an update overwrite palettes or themes I made?自己建的色板/主题更新后会被覆盖吗？
No. Your own palettes/<name>.py is not overwritten — the generator discovers it by scanning the folder. If you edited palettes, git stash before git pull and git stash pop after.不会。你自己新建的 palettes/<名字>.py 不会被覆盖，生成器扫目录自动发现。改过色板或自己加过主题，git pull 前先 git stash，拉完再 git stash pop。
How many machines can one purchase cover?买一次能装几台机器？
As many devices as you own or manage — no machine limit, personal or commercial use. One license covers one person; companies and teams buy by headcount.你本人拥有或管理的设备不限台数，个人与商业用途都行。一份授权对应一位自然人；公司或团队按人数购买。
Are imported community themes part of the product?导入的社区主题算产品内容吗？
No. Colors imported with import.sh stay on your machine only — they do not enter the product package and are not distributed with updates.不算。import.sh 导入的配色只在你机器上，不进产品包，也不会随更新分发。
