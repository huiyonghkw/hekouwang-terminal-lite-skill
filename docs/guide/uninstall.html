Uninstall卸载

Restore from backup — not a blind delete.从备份还原 —— 不是盲删。

uninstall
$ ./scripts/uninstall.sh --dry-run
$ ./scripts/uninstall.sh

Restores ~/.zshrc from the latest file under ~/.hekouwang-terminal-backups/. GUI settings return via defaults delete where applicable.从 ~/.hekouwang-terminal-backups/ 最新备份还原 ~/.zshrc。GUI 在适用处用 defaults delete 回到默认。

See also Doctor for status and parity checks before you remove anything.卸之前可先看体检的状态与 parity。
