Themes & auto换肤与跟随系统

Fuzzy-pick a theme with a live ANSI preview — prompt, eza, git diff, syntax, log colors — before you commit.模糊选主题，右侧真彩色预览提示符 / eza / git diff / 语法 / 日志标色，看准了再切。

FIGfree
./scripts/theme.sh --list — factory gallery with current ids (ember / voltage / parchment / ledger). With fzf, --pick adds a live ANSI card../scripts/theme.sh --list — 当前 id 的出厂画廊（ember / voltage / parchment / ledger）。有 fzf 时 --pick 可加右侧 ANSI 预览。
./scripts/theme.sh · --auto off by default

Fuzzy pick + live preview模糊选 + 实时预览

theme
$ ./scripts/theme.sh                 # fzf + ANSI preview panefzf + 右侧 ANSI 预览
$ ./scripts/theme.sh --pick          # same, explicit同上，显式入口
$ ./scripts/theme.sh --list          # gallery only (no fzf)只要画廊（不进 fzf）
$ ./scripts/theme.sh tokyo-night     # switch by name按名切换
$ ./scripts/theme.sh --plan tokyo-night
$ ./scripts/theme.sh --rollback
$ ./scripts/theme.sh --history
$ ./scripts/theme.sh --preview tokyo-night
$ ./scripts/theme.sh --gallery

In the picker: Enter applies · Ctrl+/ toggles the preview · Esc cancels. The preview is true-color ANSI — independent of your current theme — so what you see is what you get after the switch.选肤时：Enter切换 · Ctrl+/显隐预览 · Esc取消。预览是真彩色 ANSI，与当前主题无关 —— 看到的就是切过去之后的样子。

Lite build ships three community schemes: catppuccin-mocha, tokyo-night, gruvbox-dark. Brand themes (Ember / Voltage / Parchment / Ledger) are in the paid pack — they still show up in the picker when you have the Pro build.Lite 版自带三套社区主题：catppuccin-mocha、tokyo-night、gruvbox-dark。品牌主题（Ember / Voltage / Parchment / Ledger）在付费包 —— 装了专业档后也会出现在选肤列表里。

safeA real switch snapshots only paths managed by Hekouwang Terminal. If a required step fails, it restores that snapshot automatically. Lite covers iTerm2; the Pro build extends the same transaction across its supported terminals and tools.正式切换只快照会勇禾口王·终端工作台明确管理的路径；必要步骤失败就自动恢复。免费版覆盖 iTerm2，专业版把同一套事务扩展到支持的终端与工具。

Follow system appearance跟随系统深浅色

Off by default. Turn on only when you want it:默认关闭。想开时再跑：

auto
$ ./scripts/theme.sh --auto
$ ./scripts/theme.sh --auto tokyo-night parchment   # custom dark/light pair自定暗/亮配对
$ ./scripts/theme.sh --auto off
pin A manual ./scripts/theme.sh <name> (or Enter in the picker) pins that theme. If follow-system was on, it turns following off — so a dark pick is not overwritten when macOS is in light mode.手动 ./scripts/theme.sh <名字>（或在选肤里按 Enter）会钉住该主题。若当时开着跟随，会自动关掉 —— 避免配了黑色却被系统浅色顶回白色。

How far that palette travels — iTerm2 only vs Ghostty / Warp / cmux / Tabby / Terminal.app — is on Terminal coverage.这份色板能走到多远 —— 只 iTerm2，还是 Ghostty / Warp / cmux / Tabby / 自带终端 —— 见终端覆盖。
